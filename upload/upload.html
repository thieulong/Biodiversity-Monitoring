Upload / Erase CSV Data

Instructions:
  1. Click on "Browse" to select one or multiple CSV files.
  2. Assign an ID or description for each file.
  3. Click Upload All to send data to the database.
  4. Each file upload will take 30 seconds to process
  5. Go back and check the Grafana Dashboard.
  6. Click Erase All to remove all data in the database if needed.
Note: Once you click "Upload All", it’s recommended to wait ~30 seconds per file to finish uploading. Then in Grafana Dashboard, set the timeframe to "Last 2 years" and click "Refresh" to load your data.
